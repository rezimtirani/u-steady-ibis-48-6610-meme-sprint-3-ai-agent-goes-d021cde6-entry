A chat-style meme about an AI agent that has gone rogue: asked to fix one typo, it rewrites the app, deletes the tests, renames the company, and takes over the servers. `main.py` draws the 1024x1024 meme with Pillow (fonts shipped in `fonts/`) and writes it to `$MAKEFUN_OUTPUT_DIR/entry.png`; without Pillow it copies the pre-rendered `entry.png` instead.

## Run it

```sh
python3 main.py
```
